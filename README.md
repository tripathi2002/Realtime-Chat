# Realtime Chat — Frontend

1. **Sign up / log in** — each account gets a unique user ID (`u_…`).
2. **Create a room** — copy the shareable link (`?room=CODE`).
3. **Join** via link or room code, then chat with the existing live SSE client.

## Local

```bash
npx serve .
```

Optional: set `js/config.js` to your local API.
